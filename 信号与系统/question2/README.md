# 滤波器设计，学时1.5天
研究数字滤波器设计思想，理解数字频率与模拟频率的关系，掌握数字系统处理模拟信号的方法。掌握窗函数设计FIR数字滤波器的方法，理解FIR滤波器的线性相位重要意义。

（a）设计FIR数字低通滤波器，截止频率，在不同窗口长度（N=15，33）下，分别求出h(n)，通过幅频特性和相频特性，观察3dB带宽和20dB带宽，总结窗口长度N对滤波特性的影响；

（b）以连续信号为例，其中为噪声信号，设计数字滤波器，滤除噪声恢复信号；

（c）求出滤波器系数向量后，不利用filter函数，利用时域卷积或频域乘积完成滤波。

（3）声音信号分析与处理，学时1天

(4)利用声音信号的特殊频带，通过加入噪声，设计滤波器对噪声进行处理，达到对声音信号分析与处理的目的。
